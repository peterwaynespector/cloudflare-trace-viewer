Tentang Data Ini

Data ini diambil dari Cloudflare Trace API, endpoint publik yang mengembalikan informasi detail tentang koneksi Anda. Kami tidak menyimpan data Anda - semua proses terjadi di browser Anda.

  • IP Address: Alamat IP publik yang dikenali oleh Cloudflare
  • Lokasi: Lokasi geografis berdasarkan geolocation database Cloudflare
  • Protokol: Versi HTTP dan TLS/SSL yang digunakan untuk koneksi
  • Keamanan: Status enkripsi dan perlindungan koneksi Anda
